# Python-project
Exploratory data analysis and visualization with Python (Jupyter).

## 📖 Project Introduction and Overview
This project focuses on cleaning, analysing, and exploring Chicago crime data to identify patterns, trends, and insights.  
The analysis is conducted in **Python** using **Jupyter Notebook**, leveraging libraries for data manipulation and visualization.

## 🎯 Objective
- Clean, analyse and explore Chicago crime data  
- Identify crime patterns and temporal trends  
- Provide visual insights to support public safety analysis  

## 📂 Data
The dataset source can be found [here](https://data.cityofchicago.org/Public-Safety/Crimes-2001-to-Present/ijzp-q8t2/about_data) from the City of Chicago data repository.  
It contains multiple columns including identifiers, crime types, location details, arrest status, and geographic coordinates.  

## 🛠️ Tools & Libraries
- **Python**  
- **Jupyter Notebook**  
- **Pandas** – data cleaning and manipulation  
- **Matplotlib / Seaborn** – visualization  
- **NumPy** – numerical operations  

## 🧹 Data Cleaning
Steps performed:
1. Handle missing values  
2. Drop unnecessary columns  
3. Standardize and clean data types  
4. Add derived columns for analysis  
5. Remove duplicates  

## 🔎 Exploratory Data Analysis (EDA)
EDA includes:
- General descriptive statistics  
- Identification of predominant crime types  
- Temporal analysis (monthly, daily distribution)  
- Arrest and domestic incident trends  
- Geographic analysis of crime hotspots  

## 📈 Key Insights
- Most frequent crime categories  
- Seasonal/temporal crime patterns  
- Areas with highest crime concentration  
- Arrest and domestic incident distributions  

## 🚀 Future Improvements
- Interactive dashboards with **Plotly** or **Power BI**
